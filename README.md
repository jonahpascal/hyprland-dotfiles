# My Hyprland Dotfiles (Latest Hyprland + Alacritty)

Configuration optimisée pour **CachyOS / Arch Linux** (AZERTY + GPU Intel + Alacritty).

## 🚀 Installation rapide sur CachyOS

Ouvre un terminal sur ta session CachyOS et lance :

```bash
git clone https://github.com/<TON_USERNAME>/<TON_REPO>.git ~/dotfiles
cd ~/dotfiles
chmod +x install.sh
./install.sh
```

## ⌨️ Raccourcis Principaux

| Raccourci | Action |
|---|---|
| `Super + Entrée` | Terminal (Alacritty) |
| `Super + Espace` | Lanceur d'applications (Rofi) |
| `Super + Q` | Fermer la fenêtre active |
| `Super + F` | Plein écran (Fullscreen) |
| `Super + V` | Basculer en mode flottant |
| `Super + [1-9]` | Naviguer entre les workspaces (AZERTY direct) |
| `Super + Shift + [1-9]` | Déplacer la fenêtre vers un workspace |
| `Super + Clic gauche` | Déplacer une fenêtre |
| `Super + Clic droit` | Redimensionner une fenêtre |
